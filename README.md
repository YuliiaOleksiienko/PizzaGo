# 🍕 PizzaGo - Fullstack Pizza Ordering System

**PizzaGo** is a modern pizza ordering web application built on the .NET 9 stack. This project demonstrates session-based cart management, user authorization via Microsoft Identity, and dynamic UI updates using HTMX.

---

## 🚀 Key Features

### For Clients:
* **Pizza Menu:** Browse a list of available pizzas with prices and descriptions.
* **Smart Cart:** Add items, change quantities (+/-), and remove products without a full page reload (HTMX).
* **Ordering System:** Complete checkout process with data persistence in a PostgreSQL database.
* **Personal Dashboard:** Order history (My Orders) and user profile management (in development).
* **Security:** Secure registration and login powered by Microsoft Identity.

### For Administrators (in development):
* View a complete list of incoming orders.
* Calculate total restaurant revenue.

---

## 🛠 Tech Stack

* **Backend:** ASP.NET Core MVC (.NET 9)
* **Database:** PostgreSQL (Entity Framework Core)
* **Auth:** Microsoft Identity (Cookies & JWT)
* **Frontend:** Razor Pages, HTMX, Bootstrap 5, Bootstrap Icons
* **Data Flow:** DTOs (Data Transfer Objects), Repository/Service Pattern
